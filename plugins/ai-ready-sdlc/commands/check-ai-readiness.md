# Check AI Readiness

Evaluate whether the repository has the expected AI manifest, observability, policy alignment, and standards artifacts for AI-enabled development.

Preferred execution model:

- use the shared runner bundled with this Augment plugin package,
- target the current repository with `--repo-path .`,
- write outputs to `reports/ai-readiness.json` and `reports/ai-readiness.md` in the current repository.
