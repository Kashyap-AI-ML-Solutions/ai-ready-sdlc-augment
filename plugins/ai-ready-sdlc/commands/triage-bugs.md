# Triage Bugs

Run structured bug triage against the AI-ready SDLC standard and populate the shared triage fields where possible.

Preferred execution model:

- use the shared runner bundled with this Augment plugin package,
- target the current repository with `--repo-path .`,
- write outputs to `reports/bug-triage.json` and `reports/bug-triage.md`.
