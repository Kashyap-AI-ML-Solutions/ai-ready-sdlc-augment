# ADLC Harness Local Override

This local command is optional. The installed `ai-ready-sdlc` Augment plugin is the default discovery surface.

Use `/ai-ready-sdlc:steer-adlc-harness` for feature, bugfix, unit-test, remediation, or orchestration work. The canonical plan must live under `.adlc/plans/<YYYY-MM-DD>_<task-slug>/` before implementation starts.
