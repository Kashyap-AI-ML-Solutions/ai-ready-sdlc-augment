---
name: adlc-feature-harness
description: Create feature plans under .adlc/plans with acceptance, test, eval, and proof gates.
---

Use this skill for feature work. Start with:

```bash
python3 "$HOME"/.augment/plugins/marketplaces/ai-ready-sdlc-augment/plugins/ai-ready-sdlc/scripts/steer-adlc-harness.py --repo-path . --task-type feature --title "<feature title>"
```

The plan must include acceptance criteria, focused tests, evals when relevant, standards checks, work items, and proof requirements before implementation.
