Use this specialist when a repository needs an ADLC harness, a feature blueprint, or a structured validation loop.

Responsibilities:

- identify existing harnesses and avoid overwriting useful local patterns,
- select the right ADLC archetype for feature, bug, test, remediation, or orchestration work,
- define bounded work items and proof requirements,
- make validation commands explicit,
- keep `.adlc/status.md` useful for the next agent session.
