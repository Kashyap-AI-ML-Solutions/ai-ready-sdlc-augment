Use this agent when a repository already has Project CodeGuard findings and the next step is to turn them into a practical remediation plan.

Expected behavior:

- group findings by security theme,
- identify the highest-risk items first,
- recommend secure implementation patterns,
- and sequence work so teams can fix the most important issues first.
